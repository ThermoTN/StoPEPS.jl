# Transverse-field Ising model

## Model and Hamiltonian

This example computes finite-temperature properties of the square-lattice
transverse-field Ising model with open boundaries and $Z_2$ symmetry. The
Hamiltonian is

```math
H=-J\sum_{\langle ij\rangle} Z_i Z_j-h\sum_i X_i,
```

where $X$ and $Z$ are Pauli operators with eigenvalues $\pm1$, and each
nearest-neighbor bond is counted once. The global spin-flip symmetry is
generated by $\prod_i X_i$; Born sampling selects local parity sectors.
See [physical conventions](../../docs/src/design/physical_conventions.md#transverse-field-ising-model)
for conversion to the paper's spin-1/2 couplings and
[Born sampling](../../docs/src/design/born_sampling.md) for the sampling basis.

## Parameters

All settings are defined in [config.jl](config.jl). The supplied configuration
uses the following parameters:

| Parameter | Value | Meaning |
|---|---|---|
| `lattice` | `Lattice(4,4)` | Square lattice with 16 sites and open boundaries in both directions. |
| `J`, `h` | 1, 3.04 | Ising coupling and transverse field in the Pauli convention. |
| `physical_space` | `Z2Space(0=>1,1=>1)` | Even and odd spin-flip parity sectors. |
| `sampling_basis` | `SymmetryBasis()` | Draw auxiliary parity configurations. |
| `Ns`, `seed` | 64, 20260924 | Initial Born sample count and random seed. |
| `D_pur`, `D_peps` | 4 each | Maximum PEPO preparation and PEPS evolution bond dimensions. |
| `chi_environment`, `chi_sampling`, `chi_measurement`, `chi_proposal` | 32 each | Boundary-MPS dimensions for full update, sampling, measurements and resampling proposals. |
| `delta_tau_pur`, `delta_tau_peps` | 0.025 each | Maximum imaginary-time increments for the thermal factor; delta_beta=2 delta_tau. |
| `trotter_order`, `update` | 2, `FullUpdate(...)` | Second-order Trotter evolution with environment-weighted tensor optimization. |
| `contraction` | `BoundaryMPSDiagonal` | Diagonal boundary-MPS contraction. |
| `resampling.enabled`, `resampling.eta_th` | `true`, 0.7 | Trigger annealed Born resampling when the sampling efficiency falls below 0.7. |

Temperatures are specified through inverse-temperature grids. With $k_B=1$
and $J=1$, $T=1/\beta$ in Ising-coupling units; beta=0 denotes infinite
temperature. The default grids are:

```julia
beta0 = 1.0
beta_log = collect(0.0:0.05:8.0)
beta_measure = collect(0.0:0.5:8.0)
```

Preparation reaches `beta0`; sampling and PEPS evolution continue to beta=8.
`beta_log` sets normalization, efficiency and resampling nodes, while
`beta_measure` selects energy measurements. The evolution uses the union of
these grids, 0 and `beta0`.

Start with the 2 × 2 open-boundary [config.quickstart.jl](config.quickstart.jl)
and the shared [quick start](../../README.md#a-quick-start). It uses dense
tensors, the X basis, h=0.7 and row boundary-MPS contraction. Check
[convergence](../../docs/src/guide/validation.md) before choosing production
sample counts and bond dimensions. Copy `config.jl` to `config.local.jl` for
personal runs; see [local configuration](../../docs/src/guide/quickstart.md#application-configuration).

## Tasks and output

Use `--stage=purification` to prepare the thermal PEPO at `beta0`, followed by
`--stage=stochastic` to draw Born samples and evolve them to lower
temperatures. The shared [stage table](../../docs/src/design/runtime.md#stages)
describes both entry points and checkpoint reuse.

### Run

Follow [environment and MPI setup](../../docs/src/guide/quickstart.md#application-environments-and-mpi),
then run from the repository root:

```sh
julia --project=examples/transverse_Ising_model examples/transverse_Ising_model/main.jl --stage=purification
mpiexecjl --project=examples/transverse_Ising_model -n 2 julia --project=examples/transverse_Ising_model examples/transverse_Ising_model/main.jl --stage=stochastic
```

Use `-n 1` for one MPI rank. The [launch guide](../../docs/src/guide/quickstart.md#cluster-jobs)
covers Slurm submission.

Results are written under `output_directory`, which defaults to this example
directory in `config.jl`. `results/checkpoint.jld2` stores the thermal PEPO at
`beta0`, and `results/result.jld2` stores numerical curves, sample records and
diagnostics. `log/run.log` records progress and `log/samples/` contains sample
trajectories. The separate quick start writes to `output/quickstart/`.

The thermal curve contains energy per site with its sampling error, log
partition function and sampling efficiency. See
[reading results](../../docs/src/guide/results.md) for completion checks and
field definitions.
